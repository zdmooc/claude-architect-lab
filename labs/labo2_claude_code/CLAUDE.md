# Projet : mini-API « devis assurance auto » (fictif, labo M5)

## Contexte
Service Python qui calcule un devis d'assurance auto. Données 100 % synthétiques.

## Commandes
- Tests : `python -m pytest -q`
- Lancer un calcul : `python -m src.devis`

## Règles d'équipe
- Toute règle de tarification est couverte par un test dans `tests/`.
- Pas de secret dans le code : configuration par variables d'environnement.
- Messages de commit en français, à l'impératif.
