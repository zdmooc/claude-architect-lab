# claude-architect-lab

Laboratoire personnel de préparation aux certifications **Claude Certified Architect – Foundations** puis **Professional**.

- Données : **uniquement synthétiques** (aucune donnée client, aucun secret committé).
- Langue : français, termes techniques en anglais.

## Organisation

| Dossier | Contenu |
|---|---|
| `docs/` | Parcours, leçons et synthèses |
| `labs/` | Laboratoires pratiques (ajoutés au fil des modules) |

Voir [docs/parcours.md](docs/parcours.md) pour le programme et l'avancement.

## Par où commencer
1. `docs/lecons/M0-L1-fonctionnement-llm.md`, puis les leçons dans l'ordre M0 → M9.
2. Chaque leçon : cours, exemple, exercice guidé, exercice à toi (corrigé après ta réponse).
3. Les labos sans API (`labs/m3/test_outils.py`, `labs/m4/test_serveur.py`, `labs/labo1_support/test_hook.py`, `labs/m7/*.py`) tournent sans clé.
