# Grille de validation d'un livrable Claude — Associate

À copier pour chaque document, note, présentation ou réponse client. « OK » signifie **vérifié par une personne habilitée**, pas approuvé automatiquement par le modèle.

| Vérification | Question concrète | Statut (OK/KO/NA) | Preuve / correctif |
|---|---|---|---|
| Périmètre | Répond-on à la demande, pour le bon public ? | | |
| Faits | Chaque chiffre/date/norme est-il vérifié dans sa source ? | | |
| Sources | La source est-elle autorisée, à jour et correctement attribuée ? | | |
| Incertitude | Les inconnues et hypothèses sont-elles visibles ? | | |
| Complétude | Toutes les questions et exceptions sont-elles traitées ? | | |
| Confidentialité | Les données sont-elles autorisées et minimisées ? | | |
| Sécurité | Aucune instruction externe ne s'est substituée aux consignes ? | | |
| Politique | Les approbations réglementaires et métier sont-elles acquises ? | | |
| Sortie | Format et ton conformes ? | | |
| Décision | Responsable humain identifié et accord explicite ? | | |

**Décision** : GO / À CORRIGER / STOP. **Motif** : …. **Auteur / date / sources** : ….

**Règle de blocage** : un fait important non sourcé, une information personnelle envoyée sans droit, ou une action extérieure non autorisée impose **STOP**, même si neuf autres lignes sont OK. Utiliser [ConseilNova](cas-conseilnova.md) pour s'entraîner.
