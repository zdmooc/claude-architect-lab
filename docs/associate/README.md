# Claude Certified Associate — Foundations (CCAO-F)

**Public** : consultants, chefs de projet, avant-vente, responsables de livraison et utilisateurs métier. Parcours francophone, sans prérequis de programmation, fondé sur **sept domaines d'examen**.

**Format officiel à revérifier avant inscription** : 60 questions (choix unique et multiple), 120 min, score de passage 720 sur une échelle 100–1 000, **99 USD**, validité 12 mois ; anglais. La note 720 n'est **pas** l'équivalent de 72 % de réponses correctes. Cette certification **ne compte pas** pour le niveau de partenariat Claude Partner Network.

**Référence** : [page officielle Associate](https://anthropic-partners.skilljar.com/claude-certified-associate-foundations-certification), [cours officiel](https://anthropic-partners.skilljar.com/path/claude-certified-associate-foundations), [FAQ officielle](https://anthropic-partners.skilljar.com/page/faq-certifications). Guide d'examen v1.0 (juillet 2026) : contrôler sa version avant toute préparation finale. Ce contenu est **original, non affilié à Anthropic**.

## Exercices et preuves

- [Cas métier ConseilNova](cas-conseilnova.md) : qualifier une demande d'un client, sélectionner la solution, produire puis contrôler un livrable et faire un handover.
- [14 questions originales avec corrigés](entrainement.md) : 2 questions par domaine, incluant plusieurs cas où l'erreur plausible est dangereuse.
- [Grille métier](grille-validation.md) : critères utilisables sans savoir coder, refus de livraison en l'absence de preuves.
- Correspondances utiles : [Architect Foundations](../parcours.md) pour MCP/API ; [Developer Foundations](../developer/README.md) pour l'implémentation. Ces contenus techniques sont **facultatifs** en préparation Associate.

## Parcours de travail

1. Lire A5 → A4 → A1 pour maîtriser le choix de l'outil, les consignes et la validation.
2. Lire A6 → A2 pour industrialiser la connaissance et les handoffs.
3. Lire A3 → A7, terminer le cas ConseilNova et l'entraînement.
4. Conserver les preuves : prompt/version, sources, grille, correction, validation humaine, limites et consentement selon la politique de l'entreprise.
5. Comparer les domaines et objectifs au guide officiel **au moment du passage** : les cours seuls ne certifient pas.

Les exemples, noms, factures et données de ConseilNova sont **synthétiques**.
